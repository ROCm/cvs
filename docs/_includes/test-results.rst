The test output is captured in an HTML report generated by PyTest.
It provides a summary of passed and failed test cases. You can navigate to logs directly from the report.

``cvs run`` writes that HTML report and a text log under ``<workspace>/cvs_runs/<run_id>/`` by default (see ``--workspace``). Pass ``--html`` or ``--log-file`` to override the path, or ``--no-html`` / ``--no-log-file`` to skip a file.

.. tip::

  If errors prevent tests from starting, CVS prints a message with a suggested fix in the console.
